# Abstract Factory

## Що це

Патерн, який створює **сімейство взаємопов’язаних продуктів (об'єктів)**, що повинні використовуватися разом і відповідати одній темі без зазначення їх конкретних класів, наприклад, візуальні компоненти під різні платформи.

## Яку проблему вирішує

У системах часто потрібно створювати **комплекти об’єктів**, які повинні "працювати разом". Наприклад:

- різні теми інтерфейсу (Light / Dark), де є кнопки, інпути, чекбокси;
- різні набори UI-компонентів під різні платформи (Windows / macOS);
- різні конфігурації ігрових світів (Fantasy / Sci-Fi), де є власні герої, монстри і предмети.

Проблеми, які виникають без Abstract Factory:

- логіка створення пов’язаних об’єктів розкидана по коду;
- легко змішати несумісні об’єкти (наприклад, Dark кнопка + Light інпут);
- важко замінити всю "сімʼю" продуктів одним махом;
- багато `if/switch`, щоб визначити, який набір об’єктів створювати.

Це веде до дублювання, залежностей на конкретні класи та порушення OCP (Open/Closed Principle).

## Як вирішується проблема

Abstract Factory створює **фабрику фабрик** — об’єкт, який повертає набір пов’язаних продуктів.

Наприклад:

- `UIFactory` повертає `Button`, `Input`, `Checkbox` в одному стилі;
- `GameWorldFactory` створює `Hero`, `Monster`, `Weapon` однієї тематики.

Клієнтський код працює тільки з абстракцією:

- з інтерфейсом фабрики (наприклад, `ThemeFactory`);
- зі спільними інтерфейсами продуктів (`Button`, `Input`, `Dialog`).

## Аналогія з життя
Уяви, що ти купуєш комплект меблів для кімнати.

Ти не купуєш:

- стіл із одного магазину,
- шафу з іншого,
- крісло з третього.

Вони можуть не підходити один до одного.

Зазвичай ти купуєш готовий набір:

- стіл,
- шафа,
- ліжко,
- крісла

— усі в одному стилі (скандинавський, вінтаж, мінімалістичний тощо).

Тут Abstract Factory — це магазин комплектів.
Ти кажеш: “_Дайте весь набір у стилі Мінімалізм”_”.

І отримуєш повний набір, у якому всі елементи узгоджені між собою.

Клієнт (ти) не знає і не контролює, які конкретні класи створюються.
Ти просто отримуєш повний комплект, що гарантовано “підходить” один до одного.

# Design Patterns — Practical Examples

Цей репозиторій містить практичні приклади патернів проєктування на  
- **JavaScript**
- **TypeScript**
- **Python**

Мета — не просто пояснити теорію, а показати **живі приклади**, які можна запускати, змінювати і переносити у реальні проєкти.
Кожен патерн містить:
- короткий опис;
- проблему, яку він вирішує;
- реальну аналогію;
- приклади реалізації на різних мовах.

## 🏃 Запуск паттернів в консолі
для ts прикладів - `make run-ts pattern={path-to-the pattern}`
для js прикладів - `make run-js pattern={path-to-the pattern}`
для pyton прикладів - `make run-py pattern={path-to-the pattern}`

Наприклад
```
make run-ts pattern=creational/abstract-factory
```
